# Pathfinding Lab

Pythonilla toteutettu reitinhakualgoritmien vertailusovellus.

Sovelluksessa vertaillaan A\*- ja Fringe Search -algoritmien toimintaa ja suorituskykyä graafisella käyttöliittymällä.

Projektin tarkempi kuvaus, asennusohjeet ja käyttöohjeet löytyvät repositorion juurihakemiston README-tiedostosta.
